# Friday 13 November 2026 — the whole day in one picture

make.fun bounty **news-image-01**: sum up 13 November's world news in one
image. Second entry (variant): a dense broadsheet infographic following
the bounty's winning meta — 27 numbered stories, a big lead with stats,
an "ALSO ON..." strip, and a sources footer, all drawn programmatically
so every word is perfectly legible.

Lead story: the FAA's nationwide ground stop — the first since 9/11 —
nearly 5,000 flights cancelled, 10,000+ delayed. Also inside: Iran's
radar claim in Bahrain, the Trump–Xi–Putin meeting, Starship Flight 15,
Pope Leo XIV in Peru, Nvidia below $4 trillion, the Kyiv hospital drone
strike, the EU's five-nation Ukraine talks, the Gaza hospital strike,
the Assam bus crash, the Microsoft outage, China's drills near Taiwan,
and 14 more one-line stories.

`main.py` copies the bundled `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`). Deterministic:
repeated runs write identical bytes.
